## RackNerd 不包含哪些服务，以及谁应该跳过它

RackNerd 是非托管服务，这意味着你是服务器的系统管理员。支持为 24×7 全天候工单系统——据目录列出的正常运行时间 SLA 为 99.999%，但没有人会帮你配置或排除故障。VPS 或独立服务器不包含托管备份；RackNerd 建议自行配置异地备份，你应该在部署的第一天就设置好。目前没有免费方案，没有免费试用，且没有退款保证。此外，如果你的项目需要 S3 兼容的对象存储、负载均衡器或托管 SLA，RackNerd 并不提供这些服务。

对于确实需要这些功能的读者来说，这份缺失清单足够真实：如果你需要有人接听电话并管理服务器，或者你的业务依赖托管备份，那么这里的低价格无法弥补这些服务缺失。请寻找托管主机服务商。

然而，虚拟主机是一个例外。30–200 GB 的 cPanel 方案确实包含每日备份和免费 SSL，这就是为什么在价格允许的情况下，非技术型网站在共享托管上比在便宜的 VPS 上运行得更好。
